# 문제 1. 현재 모델 성능 확인 ==========================================
현재 코드의 평가 지표를 확인하시오.

다음 값을 출력하시오.
- MSE
- RMSE
- MAE
- R² Score

### 코드
```
from sklearn.metrics import mean_squared_error
from sklearn.metrics import mean_absolute_error
from sklearn.metrics import r2_score
import numpy as np

mse = mean_squared_error(y_test, predictions)

rmse = np.sqrt(mse)

mae = mean_absolute_error(y_test, predictions)

r2 = r2_score(y_test, predictions)

print("MSE :", mse)
print("RMSE :", rmse)
print("MAE :", mae)
print("R2 :", r2)
```
### 질문에 대해 답을 작성하시오.  ------------------------------------------------------------
1. RMSE의 의미는?
- RMSE (Root Mean Squared Error, 평균 제곱근 오차) : 오차 제곱 평균의 제곱근
- 오차 제곱으로 인해 큰 오차(이상치)에 민감하게 반응 및 강력한 패널티 부여
- 제곱근 처리를 통해 실제 타깃 데이터와 동일한 단위로 복원 (직관적 해석 용이)
- 0에 가까울수록 모델 성능 우수
2. MAE의 의미는?
- MAE (Mean Absolute Error, 평균 절대 오차) : 오차 절댓값의 평균
- 실제 오차의 평균적인 크기를 변형 없이 직관적으로 표현
- 이상치(Outlier)의 영향력이 제곱되지 않아 RMSE 대비 왜곡이 적음 (강건성)
- 0에 가까울수록 모델 성능 우수
3. R² 값이 1에 가까울수록 좋은 이유는?
- R² : 실제 데이터의 분산(변동성)을 모델이 얼마나 설명하는지 나타내는 지표
- 수식 개념: $1 - \frac{\text{모델의 오차 분산}}{\text{데이터 자체의 분산}}$
> - 이유:
> - 설명력 극대화: 1에 가까울수록 모델이 데이터의 변동 상태를 거의 완벽하게 파악했다는 의미
> - 오차 최소화: $R^2 = 1$은 모델의 예측 오차가 0인 상태를 의미하므로, 1에 가까울수록 실제값과 예측값의 일치도 상승


# 문제 2. 은닉층 추가하기 =========================================

현재
```
11 → 32 → 1
```
구조이다.
다음 구조로 변경하시오.
```
11 → 64 → 32 → 1
```

### 코드
```
self.fc1 = nn.Linear(11,64)

self.fc2 = nn.Linear(64,32)

self.fc3 = nn.Linear(32,1)
```

### 질문 ---------------------------------------------------
1. 은닉층이 늘어나면 어떤 장점이 있는가?
- 고차원적 특징(Feature) 추출 능력 향상: 입력 데이터의 복잡하고 비선형적인 패턴을 단계별로 학습 가능
- 모델의 표현력(Expressiveness) 극대화: 복잡한 경계면을 가진 데이터 분류 및 예측 문제 해결 능력 상승


2. 너무 많아지면 어떤 문제가 발생하는가?
- 과적합(Overfitting) 발생: 모델이 훈련 데이터에만 지나치게 최적화되어 실제 새로운 데이터(테스트 데이터) 예측 성능 저하
- 기리도 소실(Vanishing Gradient) 및 폭주(Exploding Gradient): 역전파(Backpropagation) 과정에서 기울기가 앞쪽 레이어로 갈수록 완전히 사라지거나 무한대로 발산하여 학습 불가능 상태 초래
- 연산 비용 및 학습 시간 급증: 파라미터(가중치 및 편향) 수의 기하급수적 증가로 인해 컴퓨터 자원 소모 극대화 및 학습 속도 저하
